# Barlow diagram lettering

Barlow Regular and Bold are included with the share-image renderer to keep text metrics and PNG bytes stable across hosts. Jeremy Tribby and the Barlow Project Authors distribute these faces under the [SIL Open Font License 1.1](OFL.txt). The files come from the [Google Fonts distribution at 6cdf018](https://github.com/google/fonts/tree/6cdf01867df0813c2390f90dff7dc66c87f14cf7/ofl/barlow).
